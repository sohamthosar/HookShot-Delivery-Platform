# Hookdeck React Console

Four original screens converted to React JSX components: Overview, Endpoints, Deliveries, and Sign in. Their original inline page scripts are mounted with component effects to keep the supplied interactions, and the original Tailwind theme, fonts, icons, colors, spacing, and component markup are retained. Use the selector at the lower right to switch screens. You can also open with `?screen=login`, `?screen=endpoints`, or `?screen=deliveries`.

## Run

```sh
npm install
npm run dev
```

The source uses the supplied Tailwind CDN configuration, Google Fonts, Material Symbols, and remote image URLs, so those assets require browser network access.
